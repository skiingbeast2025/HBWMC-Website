Key Features
Default Server Built-In
play.hbwmcofficial.xyz is automatically set as the default server in your multiplayer list. No manual IP setup required.
Dual Wisp Relays
Connected via high-speed Wisp relays (mercurywork.shop and al3x.dev) with automatic failover if a relay goes offline.
School & Chromebook Ready
Hosted on GitHub releases and pages to bypass personal Google account restrictions. Pure WebAssembly that runs in browser tabs.
MacBook & PC Optimized
Double-click the downloaded HTML file on any Mac or PC to play offline. Use fn+F3 for coordinates and fn+F6 for relay settings.
How to Get Started
1

Choose How You Want to Play

Click Play in Browser to launch the web client instantly, or click Download Client (.html) to save the self-contained offline version to your device.

2

Open Multiplayer

Once the game title screen appears, click Multiplayer. You will see HBW Minecraft Server already waiting in your list.

3

Connect & Login

Click on HBW Minecraft Server and select Join Server. Once in the authentication lobby, use /register <password> <password> to protect your account and start playing!
